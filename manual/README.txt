Calendars for organizations that ask automated tools not to read their website.

Save the organization's own published calendar here, named as sources.json says (for NY Phil: nyphil.pdf).
Either a PDF they publish, or page text you copy and paste into a .txt file, works.
The weekly update reads it like any other page. If the file is older than 45 days the page shows a warning.
These files stay on this computer; they are not uploaded to GitHub.
